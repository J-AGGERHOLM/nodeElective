  • Node intro
    In the first Node.js class, we introduced Node as a runtime environment that allows JavaScript to run outside the browser, enabling it to interact with servers, databases, and other backend systems. We explored the Node REPL, which allows developers to quickly test JavaScript code directly from the terminal.

  • Functions & Express
    In the second Node.js class, we focused on JavaScript functions, We covered different ways to declare functions (arrow functions, anonymous functions), and the use of callback functions. The class then introduced NPM and the package.json file as Node’s build and dependency manager, including installing packages like Expres.

  • Loops & Body Parser && XSS
    In this class, we introduced Nodemon for running the server with automatic restarts during development. We also added Express’s built-in body parser (express.json()).
    The lesson covered JavaScript array loop methods, along with guidelines for when to use them, and examples using the ternary operator and spread operator.
    We discussed XSS (Cross-Site Scripting) risks when manipulating the DOM and how to sanitize input when using .innerHTML.

  • Falsy, Methods & Styling
    In this class, we covered common issues such as the undefined.id error, which often occurs when the Express JSON body parser has not been enabled. We also looked at the spread operator for combining objects, and created a proxy endpoint in Express, fetch responses as readable streams, JavaScript date methods, and common falsy values. We also reviewed the three ways to style HTML: inline, in the header, and through an external stylesheet.

  • Express Static, ES Modules & Navigation
    In this class, we configured Express to serve static files to avoid MIME errors and restrict direct file access. The lesson then introduced ES Modules (import/export) as the preferred approach over CommonJS, and how to serve files using the path library. Finally, we covered basic frontend navigation methods, initializing Node projects with npm init, installing dependencies with npm install, and the use of optional chaining (?.) in JavaScript.

  • Scripts, Ports & Node env
    In this class, we worked with scripts in package.json to run commands through npm run. We removed magic numbers by storing values like the port in variables and introduced environment variables, including using process.env and the cross-env package.
